The advice is everywhere. The defaults have not moved.

Call it a crisis if you want. It behaves more like a bad habit with PR. With **divorce and kids tech**, the cost is rarely dramatic on day one. It is cumulative — like interest on a loan you did not mean to sign.

Students feel it as a performance that never clocks out.

People reach for more motivation, more apps, more content. Rory-mode thinking says: change the choice architecture. Treat attention like a budget with line items, not a vibe.

## The reframe

If status, ease, and default settings run the show, then “try harder” is a weak product. **consistent device rules** is a stronger one because it moves the easy path.

## A door that opens

Try it as a social object, not a private vow. Tell one person. Put it on a calendar. Remove one friction that makes the old habit win.

Younger people inherit systems older people built. Helping them means redesigning rooms, not blaming personalities.

Leave one cleaner default behind you this week. Then another.
