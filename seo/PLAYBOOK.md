# SEO Playbook — standing orders

## On every post

1. Intent first, keyword second
2. Title must earn the click without lying
3. One primary topic cluster membership
4. Internal link to ≥1 related essay when corpus allows
5. Meta description = human curiosity, not keyword list
6. Image OG when Remy Costa supplies art (optional early)

## Site-level (Engineering)

- `site` URL set in `astro.config.mjs`
- Sitemap via `@astrojs/sitemap`
- `robots.txt` present
- Fast fonts; avoid layout shift
- Prefer static HTML
