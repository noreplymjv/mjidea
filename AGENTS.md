# Mjidea Agent Operating System

This folder is a **portable digital company**.

- Org: `ORG.md`
- Roster: `team/ROSTER.md`
- Topic routing: `team/TOPIC-ROUTING.md`
- War rooms: `team/war-rooms/`
- Pipeline: `pipeline/execute.sh` · `complete-pending.sh` · `approve.sh` · `reject.sh`
- Drafts: `drafts/pending/` → approve → `site/src/content/blog/`
- Reports: `reports/` (research, audits, phase reports as `.md`)
- Rules: `.cursor/rules/mjidea-autorun.mdc`, `mjidea-execute-approve.mdc`, `reports-in-project-folder.mdc`
- Start: `START.md`

**Execute** → research + experts + **pending draft**. **Approve** → publish. Do not ask permission between research/draft phases.
