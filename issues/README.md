# Issues (optional local mirror)

Site-facing idea bank lives under the Astro site (`/issues/current/`, `/issues/future/`).

Use these folders when you want **pipeline-visible** markdown mirrors without touching the site UI:

- `issues/current/` — active thoughts to execute soon
- `issues/future/` — later

`./pipeline/complete-pending.sh` scans both. Prefer `inbox/` for new CEO floats; use `issues/` when mirroring site seeds or parking mid-formed thoughts.
